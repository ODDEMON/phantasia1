# 残像 · AFTERIMAGE

按原大纲重写的一部长线视觉小说。
视觉与引擎骨架承袭 `phantasia0`（矢量场 / 光标即光源 / 掉位不掉魅力 / 排印档 / 逐字落字 / 提示对位 / 收掉闪烁），
剧本全部重写：十五卷、三大章、六个收束。

## 打开方式

双击 `index.html`。断网可用，无构建、无依赖、无后端。

## 语言

正文与界面均提供 **中文 / English / 日本語 / Русский** 四语。切换方式有两种，且即时生效、刷新后仍在：

- 封面底部一排语言按钮；
- 左上角常驻的语言选择（永远在）。

中文永远是源；英日俄是叠加的译文层（见 `world/i18n/{en,ja,ru}.js`，键为原中文）。
切语言时，当前这一句会用新语言重新落字，正在读的不会断。

## 这一版讲了什么

**残像不是世界的里面，是世界退场之后留下的那一面。**

五块领地不是五种元素，是五种记账方式——按主客观那一层拆开：

| 属性 | 掌管者 | 记的是 |
|---|---|---|
| 木 | 青梧 | 能长成客观存在的、那种主观活动 |
| 金 | 棱 | 人的主观感受之间，那点客观的差异 |
| 土 | 套中人 | 在客观环境之下，把自己的感受递给别的精神 |
| 水 | 全息的她 | 主观感受专心去总结客观世界的细节 |
| 火 | 最短的那位 | 在一切稳定存在的事物之外，那份多出来的意愿 |

还有第六本——**真实自我**：主观意识要在客观世界里证明自己确实存在。
五本账都没有这一栏。火问出「我烧完了以后我是谁」，五本账一起停了。

主角**零**没有形状，没被任何一本账记过，是唯一能穿过五块领地而不被切碎的存在。
零的任务不是打败谁，是**替他们重新记一次账**。

- **第一大章（卷一—卷九）**：走过五领地 → 火问出那句 → 记账者罢工 → 五灵魂碎成紫蓝绿乱码 → 归返救回青梧。
- **第二大章（卷十）**：不迎二周目，只迎平行分支。四条一条一条走完（木火旧约 / 土的承重 / 棱的形状 / 海那行注释），五本账合成一本。
- **第三大章（卷十一—卷十四）**：把"疯狂"转成能力 → 五份碎片逐一抵消 → 零为剩下那堆东西起名**「光的结晶」**→ 零成为第一块 → 引渡者收笔。

## 终局

引渡者在卷十四收笔：交代她就是上一次的零，交代你落下的那个字归了这一片场，
然后直接对屏幕外那位说一句谢谢。结尾只有一句——

> 晚安。做一场五颜六色的、发光的梦哦。☆

结晶那一层（感动 / 需要 / 理念三重，把现实拆向最远离自身的方向）仍然成立，
它是世界换底层的原理；只是它不通向死亡，它是"到这儿为止"，剩下的路归你。

## 这一版的规矩

- **说话人印记**：句子上方浮出名字，不用猜谁在说话。姿态照旧保留。
- **声音九个**：场 / 引渡者 / 零 / 青梧 / 棱 / 土 / 水 / 火 / 读数。
- **不立台词规范**：旧版那套禁用词表只起到反效果，已摘掉。
- **不留元层面指涉**：正文里不提"原案里写着什么"，也不建 design 文件夹。
